# Projeto Palmeiras em Java 🐷⚽

Este é um projeto simples desenvolvido em **Java** utilizando a IDE **NetBeans**. O objetivo principal é demonstrar conceitos fundamentais de programação e manipulação 
de coleções, modelando uma classe que representa o time do **Palmeiras**.

## 🚀 Funcionalidades e Características
* **Linguagem:** Java
* **IDE utilizada:** NetBeans31
* **Coleções Dinâmicas:** Uso de `ArrayList` para armazenar e gerenciar listas de dados (ex: nomes de jogadores, títulos conquistados ou histórico de partidas).
* **Foco:** Prática de encapsulamento, laços de repetição (loops) e manipulação de listas na linguagem Java.
